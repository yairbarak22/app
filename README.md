# אנגלית יומית — English Daily Trainer

לומדה אישית לתרגול יומי של **אוצר מילים, דקדוק ושטף דיבור** באנגלית, לדובר עברית ברמה B1 שרוצה להגיע ל-B2 ולדבר בביטחון.

הכול רץ בדפדפן, בלי שרת, בלי חשבון, בלי מפתחות API ובלי זיהוי דיבור. ההתקדמות נשמרת מקומית ב-`localStorage`
וניתנת לייצוא לקובץ גיבוי. הממשק והסברי הדקדוק בעברית, כל התרגול באנגלית.

## הפעלה

```bash
npm install
npm run dev          # http://localhost:3000
```

בנייה לאתר סטטי (אפשר לארח בכל מקום, גם לפתוח מקומית):

```bash
npm run build        # מייצר out/
npm start            # מגיש את out/ מקומית
```

בדיקות:

```bash
npm test             # מנוע + ולידציה של התוכן
npm run typecheck
```

## פרסום ב-GitHub Pages

האתר מתפרסם לענף `gh-pages`, וצריך לכוון את Pages אליו **פעם אחת**:

**Settings → Pages → Source: Deploy from a branch → Branch: `gh-pages` → `/ (root)` → Save**

אחרי זה האתר חי בכתובת `https://<שם-המשתמש>.github.io/app/`.
בלי ההגדרה הזאת GitHub מציג את קובץ ה-README כאתר, כי אין לו שום דבר אחר להגיש.

לעדכון האתר אחרי שינוי בקוד:

```bash
npm run deploy       # בונה ודוחף את התוצאה ל-gh-pages
```

האתר מוגש מתוך תת-נתיב (`/app/`), ולכן הבנייה מקבלת `NEXT_PUBLIC_BASE_PATH`. בפיתוח מקומי המשתנה ריק והכול רץ מהשורש.

## מבנה הקורס: 53 יחידות לימוד

הלמידה בנויה כקורס עם תוכן עניינים, לא כזרם יומי אקראי. כל יחידה היא ישיבה אחת של כ־40 דקות:

| חלק ביחידה | מה קורה |
|---|---|
| השיעור | נושא דקדוק אחד, מוסבר בעברית עם ניגוד לעברית וטעויות נפוצות |
| מילים וביטויים | 16 מילים חדשות בקבוצות של ארבע: היכרות, זיהוי, והשלמה במשפט |
| תרגול הנושא | 12 תרגילים מסוגים שונים על הדקדוק של היחידה |
| תרגום מהיר בקול | 6 משפטים מעברית, 5 שניות לכל אחד, בדיוק על המבנה שנלמד |
| משימת דיבור | מתחלף: 4/3/2, שאלות מהירות, סיפור מחדש, או הקראה |
| סיכום | לדבר דקה, לכתוב מה שאמרת, ולקבל סריקת שגיאות |

אחרי כל חמש יחידות מגיעה **יחידת חזרה** בלי חומר חדש, שמערבבת את חמשת הנושאים האחרונים.
היחידות מסודרות ב־10 פרקים לפי נושא: זמנים, מודאלים, תנאי, סביל ודיבור עקיף, שאלות, תוויות ושמות עצם,
מילות יחס, תבניות פועל, פסוקיות והשוואה, וסדר מילים.

בתוכן העניינים רואים לכל יחידה את האחוז שהושלם, כמה תרגילים נעשו מתוך כמה, וכמה זמן היא לוקחת. אפשר
לפתוח כל יחידה ולראות מה בדיוק היא מלמדת ואילו מילים יש בה, לקפוץ אליה גם אם היא רחוקה, ולחזור על יחידה
שכבר הושלמה. יחידה שנעצרה באמצע ממשיכה בדיוק מהמקום שבו הפסקת — מה שכבר נענה לא חוזר.

## חזרה יומית

בנפרד מהיחידות יש **חזרה** שמביאה רק את מה שהגיע זמנו: מילים וביטויים לפי מרווחי הזכירה, הנושאים החלשים
שממתינים לחזרה, והמלכודות שנתפסו בכתיבה שלך. החזרה לא מקדמת את אחוז היחידה — היא שומרת על מה שכבר נלמד.
בשבת החזרה הופכת למבחן מעורב.

## איך זה מחליט מה להראות

- **חזרות מרווחות (SM-2+)**: לכל מילה יש מרווח, קלות ומונה שכחות. תשובה נכונה מרחיקה את החזרה, שגיאה מקרבת אותה
  ומורידה שלב. מילה שנשכחה שש פעמים מסומנת כ"עקשנית" וחוזרת עם היכרות מחדש.
- **סולם שלבים למילה**: היכרות → זיהוי → השלמה במשפט → הפקה מעברית → צירוף נכון → אמירת משפט משלך.
  אותה מילה נשאלת אחרת בכל שלב, כך שהיא נבנית מזיהוי פסיבי עד דיבור.
- **מודל שליטה בדקדוק (BKT)**: לכל נושא הסתברות שהוא נלמד, שמתעדכנת אחרי כל תשובה ולוקחת בחשבון ניחוש
  באמריקאיות. נושא נחשב נשלט רק אחרי 12 תרגילים לפחות בשלושה ימים שונים.
- **סדר הנושאים**: הסילבוס בנוי לפי קדם-דרישות אמיתיות (עבר פשוט לפני עבר מושלם, תנאי ראשון לפני שני), ולכן
  סדר היחידות הוא הסדר המומלץ — אבל אתה חופשי לקפוץ.
- **סדר המילים בקורס**: המילים ממוינות לפי רמת קושי, ובתוך כל רמה מעורבבות בין נושאים, כך שכל יחידה מקבלת
  מנה מאוזנת ולא 16 מילים מאותו שדה סמנטי.
- **שמיעה לפני הפקה**: מילה חדשה, ביטוי חדש ותשובה שנחשפה מושמעים אוטומטית (ניתן לכיבוי), כך שאתה שומע את
  ההגייה לפני שאתה מנסה להגיד אותה בעצמך. בתרגילי השלמה מושמע המשפט השלם, לא המילה הבודדת.
- **מלכודות מהעברית**: מה שאתה כותב בשלב הסיכום נסרק מול 40 דפוסי שגיאה אופייניים לדובר עברית ומול כללי
  התאמה, זמנים ותוויות. כל מלכודת שנתפסת נכנסת לתור התרגול של הימים הבאים.

## מבנה הקוד

```
engine/     לוגיקה טהורה ובדוקה: curriculum, srs, mastery, planner, grader, errorScan, level, rng
content/    כל התוכן כ-TypeScript מוקלד: vocab/, grammar/, fluency/, chunks, interference, placement
components/ רכיבי תרגול (אוצר מילים, דקדוק, שטף) + רכיבי ממשק
app/        עמודים: היום, יחידות (תוכן עניינים), סשן, התקדמות, מילון, הגדרות, מבחן מיון
lib/        טיפוסים, store מקומי, פעולות
scripts/    ולידציה של התוכן (רץ כחלק מהבדיקות)
```

הוספת תוכן היא הוספת פריט למערך המתאים תחת `content/`. `npm test` בודק שהפריט תקין: מזהה ייחודי, מקום אחד
בדיוק ל-`___`, תשובה שאפשר לבדוק, הסבר בעברית, קדם-דרישות שקיימות ואין בהן מעגל.
