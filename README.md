# אנגלית יומית — English Daily Trainer

לומדה אישית לתרגול יומי של **אוצר מילים, דקדוק ושטף דיבור** באנגלית, לדובר עברית ברמה B1 שרוצה להגיע ל-B2 ולדבר בביטחון.

הכול רץ בדפדפן, בלי שרת, בלי חשבון, בלי מפתחות API ובלי זיהוי דיבור. ההתקדמות נשמרת מקומית ב-`localStorage`
וניתנת לייצוא לקובץ גיבוי. הממשק והסברי הדקדוק בעברית, כל התרגול באנגלית.

## הפעלה

```bash
npm install
npm run dev          # http://localhost:3000
```

בנייה לאתר סטטי (אפשר לארח בכל מקום, גם לפתוח מקומית):

```bash
npm run build        # מייצר out/
npm start            # מגיש את out/ מקומית
```

בדיקות:

```bash
npm test             # מנוע + ולידציה של התוכן
npm run typecheck
```

## הסשן היומי

התוכנית נבנית מחדש כל בוקר לפי מצב הלמידה, ומחולקת לשלבים עם תקציב זמן (ברירת מחדל 60 דקות):

1. **חימום** — חזרות מרווחות על מילים וביטויים שהגיע זמנם
2. **דקדוק** — שיעור בנושא הנוכחי, ואז תרגול משולב עם 2–3 נושאים אחרונים
3. **שטף א׳** — תרגום מהיר בקול, 5 שניות למשפט, ממוקד בנושא הדקדוק של היום
4. **מילים חדשות** — היכרות, זיהוי והשלמה במשפט, בקבוצות של ארבע
5. **חזרה מרווחת** — הנושאים החלשים שהגיע זמנם + מלכודות שנתפסו בכתיבה שלך
6. **שטף ב׳** — מתחלף לפי יום: 4/3/2, שאלות מהירות, סיפור מחדש, או הקראה
7. **סיכום** — לדבר דקה, לכתוב מה שאמרת, ולקבל סריקת שגיאות

בשבת אין חומר חדש: יום חזרה + מבחן שבועי מעורב.

## איך זה מחליט מה להראות

- **חזרות מרווחות (SM-2+)**: לכל מילה יש מרווח, קלות ומונה שכחות. תשובה נכונה מרחיקה את החזרה, שגיאה מקרבת אותה
  ומורידה שלב. מילה שנשכחה שש פעמים מסומנת כ"עקשנית" וחוזרת עם היכרות מחדש.
- **סולם שלבים למילה**: היכרות → זיהוי → השלמה במשפט → הפקה מעברית → צירוף נכון → אמירת משפט משלך.
  אותה מילה נשאלת אחרת בכל שלב, כך שהיא נבנית מזיהוי פסיבי עד דיבור.
- **מודל שליטה בדקדוק (BKT)**: לכל נושא הסתברות שהוא נלמד, שמתעדכנת אחרי כל תשובה ולוקחת בחשבון ניחוש
  באמריקאיות. נושא נחשב נשלט רק אחרי 12 תרגילים לפחות בשלושה ימים שונים.
- **פתיחת נושאים**: לכל נושא יש קדם-דרישות, ונושא נפתח רק כשהן נלמדו. הסדר הוא סילבוס אמיתי, לא רשימה אקראית.
- **קצב מילים חדשות**: יורד כשנערמות חזרות או שאחוז הזכירה נופל מ-80%, ועולה כשהזכירה מעל 92%.
- **מלכודות מהעברית**: מה שאתה כותב בשלב הסיכום נסרק מול 40 דפוסי שגיאה אופייניים לדובר עברית ומול כללי
  התאמה, זמנים ותוויות. כל מלכודת שנתפסת נכנסת לתור התרגול של הימים הבאים.

## מבנה הקוד

```
engine/     לוגיקה טהורה ובדוקה: srs, mastery, planner, grader, errorScan, level, rng
content/    כל התוכן כ-TypeScript מוקלד: vocab/, grammar/, fluency/, chunks, interference, placement
components/ רכיבי תרגול (אוצר מילים, דקדוק, שטף) + רכיבי ממשק
app/        עמודים: היום, סשן, התקדמות, מילון, הגדרות, מבחן מיון
lib/        טיפוסים, store מקומי, פעולות
scripts/    ולידציה של התוכן (רץ כחלק מהבדיקות)
```

הוספת תוכן היא הוספת פריט למערך המתאים תחת `content/`. `npm test` בודק שהפריט תקין: מזהה ייחודי, מקום אחד
בדיוק ל-`___`, תשובה שאפשר לבדוק, הסבר בעברית, קדם-דרישות שקיימות ואין בהן מעגל.

משימה הוא מה שמצייר את גרף השטף לאורך זמן, אז שווה להיות כן בו.
